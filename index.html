Step-By-Step Developer Guide

How to Setup & Host This Site on GitHub Pages

Follow these exact instructions to push this code to VS Code and publish it live on GitHub Pages (just like your reference website link).

1. Prepare Your VS Code Folder

Create a clean folder on your computer named poultry-ecommerce.

  1. Open VS Code.
  2. Go to File > Open Folder... and select your poultry-ecommerce folder.
  3. Create a new file named index.html.
  4. Copy and paste all code from this page directly into your index.html file.

2. Create a GitHub Repository

  1. Go to GitHub.com and sign in.
  2. Click the "+" (Plus icon) on the top right > New repository.
  3. Repository Name: poultry-store (or any name you like).
  4. Keep it set to Public.
  5. Leave "Add a README file" unchecked and click Create repository.

3. Push Code via VS Code Terminal

In VS Code, press Ctrl + ` (or go to Terminal > New Terminal), then run these commands step by step:

git init

git add .

git commit -m "Initial commit - Poultry E-Commerce website"

git branch -M main

# Replace YOUR-USERNAME and REPO-NAME with your GitHub details:

git remote add origin https://github.com/YOUR-USERNAME/poultry-store.git

git push -u origin main

4. Activate GitHub Pages

  1. Go to your repository page on GitHub.
  2. Click on Settings (top tab bar).
  3. On the left sidebar, click Pages.
  4. Under Build and deployment > Branch, select main branch and leave folder as /(root).
  5. Click Save.
  6. Wait 1-2 minutes! GitHub will generate your live URL like: https://YOUR-USERNAME.github.io/poultry-store/
